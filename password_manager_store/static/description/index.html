Password Manager Store

Odoo 17 CE & EE Fernet AES-128-CBC Immutable Audit Trail Admin-Only

Store and reveal Odoo user passwords securely — without ever resetting them. Set, view, and copy passwords directly from the user form with a tamper-proof audit trail for every action.

Settings → Users & Companies → Users → pilih user → tab Password Store

Where to Find It (Lokasi Menu)

1. User Password Store
Settings → Users & Companies → Users
→ pilih user → tab "Password Store"

Set, show, atau copy password login user tanpa perlu reset password.

2. Audit Log
Settings → Technical
→ Password Store Audit Log

Rekam jejak setiap aksi set, show, dan copy lengkap dengan timestamp dan IP address.

Fernet Encryption

AES-128-CBC + HMAC at rest. Master key stored in odoo.conf, never in the database.

Tamper-Proof Audit

Every set, reveal, and copy action is logged with admin ID, timestamp, and client IP.

No Reset Needed

View or copy a user's current password anytime — without changing or resetting it.

Admin-Only Access

Restricted to the Password Store Administrator group. Invisible to regular users.

How It Works

Automatic Capture
On every password change

Whenever an administrator sets or changes a user's password via Settings → Users or the Password Store tab, an encrypted copy is automatically stored.

Reveal Anytime
One click, fully logged

Open any user → Password Store tab → click Show Password or Copy Password. The action is immediately recorded in the audit log.

Set & Store in One Step
Built-in wizard

Use the Set & Store Password button directly from the Password Store tab to set a new password and store it encrypted in one action.

Database Isolation
Key separation guarantee

Passwords in the database are pure ciphertext. The master key lives only in odoo.conf — leaked DB backups are useless without it.

Setup in 3 Steps

Step 1 — Install Library

Install the Python cryptography library:

pip install cryptography
Step 2 — Generate Key

Generate a secure Fernet key:

python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
Step 3 — Add to odoo.conf

Add the key and restart Odoo:

password_store_key = YOUR_KEY

Keep this key safe. Lost key = lost passwords forever.
