Simple 3-Step Setup

Step 1: Prerequisites

Install the standard Python cryptography library:

pip install cryptography
Step 2: Generate Key

Generate a 32-byte Fernet key:

python3 -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
Step 3: Save to odoo.conf

Add the key to your server config & restart:

password_store_key = YOUR_KEY
